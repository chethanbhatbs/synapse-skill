# Learnings — Claude Code Skill

Capture and document what you learned from the current task — new tools, technologies, skills, concepts, or insights.

## Usage

```
/learnings [optional topic]
```

Invoke after finishing a task or when you want to record insights. The skill automatically captures:
- What was learned
- Tools/technologies involved
- Key takeaways
- Links to relevant resources

## Installation

```bash
cp -r learnings ~/.claude/skills/
```
